# Создание бота Telegram

Русский | [English](en/telegram_bot_setup.md)

## Получить токен

Откройте [@BotFather](https://t.me/BotFather).

- **Новый бот:** отправьте `/newbot`, укажите название и свободное имя пользователя, оканчивающееся на `bot`, например `school_routine_demo_bot`. Скопируйте токен из ответа BotFather.
- **Бот уже создан:** отправьте `/mybots`, выберите бота из списка, нажмите **API Token** и скопируйте текущий токен.

## Подключить к проекту

В `.env` в корне проекта укажите токен. Для экземпляра, принимающего сообщения в Telegram, выберите `tg`:

```dotenv
bot_token="ТОКЕН_ОТ_BOTFATHER"
messenger_tag="tg"
```

Рабочий `vk_bot_token` нужен для уведомлений в ВК о назначении или снятии роли дежурного по опозданиям. Если у пользователей в текущей базе есть только Telegram ID, эти уведомления отправляются только в Telegram. Поле `vk_bot_token` всё равно требуется настройкам: если ВК не используется, укажите `vk_bot_token="unused"`. Для отправки в ВК замените заглушку [настоящим токеном](vk_bot_setup.md).

При первой настройке выполните [первый запуск](../README.md#первый-запуск-через-docker-compose). Если бот уже работает, [примените изменения `.env`](deployment.md#docker-compose). Затем откройте своего бота и отправьте `/start` — бот должен попросить ввести ФИО.

## Перевыпустить токен

Если токен раскрыт или его нужно заменить:

1. Отправьте `/revoke` в @BotFather и выберите бота. Старый токен перестанет работать.
2. Сохраните новый токен в `bot_token` в `.env` на каждом сервере, где используется этот токен.
3. Из каталога проекта на каждом таком сервере примените изменения:

```bash
docker compose up -d --no-build school-routine-bot
```

Не публикуйте токен и не добавляйте `.env` в Git.
