# Создание бота ВКонтакте

[README](../README.md) · [Настройка Telegram](telegram_bot_setup.md)

Бот работает от имени сообщества и получает сообщения через Long Poll API.

## Получить ключ сообщества

1. В разделе **Сообщества** создайте сообщество или откройте существующее, которым вы управляете.
2. В управлении сообществом включите **Сообщения сообщества**, а в настройках для бота — **Возможности ботов**, чтобы работали клавиатуры.
3. Найдите **Работа с API → Ключи доступа → Создать ключ**. Разрешите доступ к сообщениям сообщества, подтвердите создание ключа и скопируйте его.
4. В **Работа с API → Long Poll API** включите Long Poll. В **Типах событий** отметьте **Входящее сообщение (`message_new`)** и сохраните настройки.

Для этого проекта нужен ключ сообщества. Требования к Long Poll описаны в [документации VKBottle](https://vkbottle.readthedocs.io/ru/latest/tutorial/first-bot/). Названия и расположение пунктов меню ВК могут отличаться.

## Подключить к проекту

В `.env` в корне проекта укажите ключ. Для экземпляра, принимающего сообщения ВКонтакте, выберите `vk`:

```dotenv
vk_bot_token="КЛЮЧ_СООБЩЕСТВА"
messenger_tag="vk"
```

Заполните также `bot_token` настоящим [токеном Telegram](telegram_bot_setup.md): текущий код создаёт Telegram-клиент даже при запуске ВК.

При первой настройке выполните [первый запуск](../README.md#первый-запуск-через-docker-compose). Если бот уже работает, [примените изменения `.env`](deployment.md#docker-compose). Затем напишите сообществу `Начать` — бот должен попросить ввести ФИО.

Не публикуйте ключ. Если он раскрыт, удалите его в настройках сообщества, создайте новый, обновите `.env` и примените изменения.
